`nf-diff` renders a single, self-contained HTML report — inline CSS/JS/SVG, no network access — with a light/dark theme toggle and a paginated sidebar (Metadata, Parameters, Configuration, Processes, Tasks, Failures, Performance, and more, depending on which optional layers were enabled).

The example below is generated by the [`examples/rich-report`](https://github.com/mribeirodantas/nf-diff/tree/main/examples/rich-report) demo pipeline — open it full-screen to click through the pages and try the theme toggle.
